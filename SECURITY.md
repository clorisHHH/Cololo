# Security Policy

## Supported versions

Security fixes are currently provided for the latest release on the `main` branch.

## Reporting a vulnerability

Please do not open a public issue for a suspected vulnerability. Use GitHub's private security advisory feature or contact the repository owner privately through GitHub with:

- a description of the issue;
- steps to reproduce;
- the affected version and operating system;
- any suggested mitigation.

Please do not include private images, API keys, model credentials, or other sensitive data in a report.
